# Data Catalog & Profiler — MANIFESTO OFICIAL DA APLICAÇÃO
#
# Este é o ÚNICO manifesto de dependências do app (Streamlit em `src/`).
# Instalação: pip install -r requirements_catalog.txt   (ver README.md)
#
# NÃO confundir com `requirements-aiox-tooling.txt`, que declara o tooling
# de IA/MCP do repositório e NÃO é usado pelo app (ver README.md § Manifestos).
#
# Regra desta lista (Story 6.2 AC6): todo pacote aqui tem uso real no código —
# import direto em `src/` ou engine exigida em runtime. Nada é declarado "por via das dúvidas".
#
# Pisos de versão (pacotes compilados): escolhidos como a primeira release com wheel
# binária `cp314-win_amd64` publicada no PyPI, porque o ambiente-alvo é Windows + Python 3.14
# e numpy/scikit-learn/pandas têm extensões compiladas (sem wheel, o pip tentaria
# compilar do source e falharia). Python mínimo suportado: 3.11 (imposto por numpy>=2.3.2).
# Sem upper bounds: o resolver do pip harmoniza as versões (scikit-learn puxa scipy/joblib).
#
# Pisos de versão (pacotes pure-Python): quando o pacote não tem extensão compilada,
# o critério de wheel binária não se aplica — a wheel publicada é universal
# (`py3-none-any`, serve qualquer plataforma/CPython). Nesses casos o piso é ditado
# pela primeira release sem vulnerabilidade conhecida (ver SEC-001, Story 6.2 QA gate).
